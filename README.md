# 高等数学零基础交互课程 · Calculus Zero

一个**纯前端、零依赖**的交互式高等数学（微积分）入门课件。用浏览器打开 `calculus-zero.html` 即可学习，无需联网、无需构建、无需安装任何环境。

## 内容结构

- **第 1 章 · 极限**：无限逼近的思想，微积分的基石（含极限逼近动画）
- **第 2 章 · 导数**：变化率与切线斜率，割线转切线动画 + 基本求导公式
- **第 3 章 · 积分**：曲边面积与累积，黎曼和动画 + 牛顿-莱布尼茨公式
- 每章配套互动练习：选择题 / 填空题 / 拖动匹配题

## 特性

- 单文件 HTML，CSS 与 JavaScript 全部内嵌，**无外部依赖**
- 交互动画由 SVG + 原生 JavaScript 实时绘制（非视频，体积小、任意浏览器可跑）
- 支持键盘方向键翻页、手机滑动手势、演示模式（按 `F` 进入全屏）

## 使用方式

直接用浏览器打开 `calculus-zero.html` 即可；也可部署到任意静态托管（如 GitHub Pages）。
